# 支付方式说明

## 支持的支付方式
| 支付方式 | 支持平台 | 到账时效 |
| :--- | :--- | :--- |
| 支付宝 | 支付宝 APP/网页 | 即时 |
| 微信支付 | 微信/小程序 | 即时 |
| 银行卡 | 各大银行 | 即时 |
| 花呗/白条 | 相应平台 | 即时 |
| 信用卡 | 各大银行 | 即时 |

## 支付限额
- 单笔订单限额 50000 元。
- 大额支付（单笔 > 5000 元）需二次身份验证。

## 支付失败处理
1. 支付失败订单保留 30 分钟，超时自动关闭。
2. 已扣款但订单未生成：系统自动对账退款，最迟 3 个工作日。
3. 重复扣款：联系客服提供支付凭证，核实后原路退回。

## 退款原路退回
- 所有退款按原支付方式退回，不跨渠道。
- 支付宝/微信退款 1-3 个工作日到账，银行卡 3-7 个工作日。
