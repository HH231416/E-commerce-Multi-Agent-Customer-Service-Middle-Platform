# 物流配送时效说明

## 发货时效
- 现货商品下单后 48 小时内发出，预售商品按页面承诺时间发出。
- 超过承诺时间未发出的，系统自动赔付订单金额 5% 的违约金，最高赔付 50 元。

## 配送时效（从出库算起）
| 地区 | 预计时效 | 说明 |
| :--- | :--- | :--- |
| 一线城市 | 1-3 天 | 北京、上海、广州、深圳、杭州、成都 |
| 二线城市 | 2-4 天 | 省会及重点地级市 |
| 三线及以下 | 3-6 天 | 偏远地区顺延 1-2 天 |
| 新疆、西藏等 | 5-8 天 | 运费按偏远地区标准收取 |

## 物流异常处理
1. **物流信息 3 天无更新**：客服核实后补发或全额退款，二选一由用户决定。
2. **包裹破损**：拒收或签收后 24 小时内反馈，凭外包装照片申请补发或退款。
3. **丢件**：物流确认丢失后，按订单金额全额退款，并补偿 20 元优惠券。

## 联系物流
用户可通过订单详情页的"查看物流"跟踪配送进度；配送异常可在帮助中心发起"物流投诉"，客服 2 小时内响应。
