# 客服操作与审批规范

## 权限审批
| 操作 | 权限 | 条件 |
| :--- | :--- | :--- |
| 发放无门槛优惠券 | 一线客服 | 情绪激动等级 > 3 级，限 20 元 |
| 例外退货特批 | 主管 | 银牌以上会员，7-15 天内 |
| 折旧退货 | 主管 | V5 钻石会员，年退货率 < 10%，扣 15% |
| 高额退款（>1000元） | 经理 | 需人工审核 |

## 高风险用户识别（风控）
1. 同一 ID 近一个月退货超过 5 单，标记高风险。
2. 高风险用户退货：必须先寄回、仓库视频拆包验货。
3. 严禁对高风险用户使用"极速退款"功能。
4. 发现调包、以旧换新等欺诈行为，立即报警并封禁账号。

## 操作留痕
1. 所有审批操作必须在工单系统记录审批人与审批理由。
2. 优惠券发放、特批退货、高额退款操作自动生成审计日志。
3. 审计日志保留 3 年，供合规与风控复查。

## 响应时效
- 普通咨询：5 分钟内响应。
- 工单处理：24 小时内首次回复。
- 投诉升级：按投诉级别在 30 分钟 - 24 小时内响应。
