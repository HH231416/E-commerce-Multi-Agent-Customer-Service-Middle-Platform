# 跨境购物与关税说明

## 跨境商品说明
跨境商品由海外保税仓直发，涉及海关清关流程，物流周期较国内订单长。

## 关税与税费
| 情形 | 税费承担 |
| :--- | :--- |
| 商品价格 ≤ 5000 元 | 按跨境电商综合税，由平台代缴 |
| 单次消费 > 5000 元 | 超出部分关税由用户承担 |
| 用户原因退货 | 往返国际运费及关税由用户承担 |
| 商品质量问题退货 | 运费由商家承担，关税可申请退还 |

## 物流时效
- 保税仓发货一般 5-10 个工作日送达。
- 海外直邮一般 10-20 个工作日送达，具体以物流显示为准。

## 退货政策
- 跨境商品除严重质量缺陷外，原则上不支持无理由退货。
- 若强行退货，用户需承担国际段往返运费及可能产生的关税。

## 常见问题
- 跨境商品订单需实名认证，请确保收件人信息与身份证一致。
- 跨境商品不参与国内平台满减活动。
