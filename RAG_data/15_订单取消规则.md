# 订单取消规则

## 可取消状态
| 订单状态 | 是否可取消 | 说明 |
| :--- | :--- | :--- |
| 待付款 | 可取消 | 关闭订单即可 |
| 待发货 | 可取消 | 取消后自动退款 |
| 已发货 | 不可取消 | 需申请退货 |
| 已签收 | 不可取消 | 需申请售后 |

## 取消流程
1. 待付款订单：订单详情页点击"关闭订单"。
2. 待发货订单：点击"取消订单"，确认后原路退款。
3. 已发货订单：进入"申请售后"选择"仅退款"或"退货退款"。

## 取消时效
- 待发货订单取消：审核通过后 1-3 个工作日退款到账。
- 已发货订单退款：需等商品退回仓库验收后处理。

## 特殊说明
- 大促预售订单取消规则以活动页为准。
- 使用优惠券的订单取消后，优惠券退回原账号。
